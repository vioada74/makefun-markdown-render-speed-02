A fast drop-in replacement for marked 18.1.3 that renders exactly the same HTML for less CPU. A dependency-free, hand-written CommonMark + GFM parser in a single parse.js module, with a small main.ts driver that renders every case from an input file.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
